# JavaScript – Structured Notes with Simple Definitions

---

## 1. Introduction to JavaScript

**JavaScript (JS)** is a **high-level, dynamically typed, interpreted scripting language** mainly used to make web pages interactive.

### Key Features

* Dynamically typed (no need to specify data type)
* Case-sensitive
* Runs in browser and server (Node.js)
* Event-driven and lightweight

### Identifiers

Identifiers are **names given to variables, functions, and objects**.

Rules:

* Must start with a letter, `_`, or `$`
* Cannot start with a number
* Cannot use reserved keywords
* Case-sensitive

```js
let firstName = "Rajesh";
let _age = 23;
let $salary = 25000;
```

Naming Conventions:

* camelCase → `firstName`
* PascalCase → `FirstName`
* snake_case → `first_name`

---

## 2. Variables

**Variable**: A variable is a **container used to store data values**.

### Types of Variable Declarations

### 2.1 var

* Function scoped
* Redeclaration allowed
* Hoisted

```js
var age = 20;
age = 21;
var age = "twenty";
```

### 2.2 let

* Block scoped
* Redeclaration not allowed
* Re-assignment allowed

```js
let newAge = 21;
newAge = "twenty one";
```

### 2.3 const

* Block scoped
* Redeclaration & re-assignment not allowed

```js
const name = "Rajesh";
```

---

## 3. Input & Output Methods

* `alert()` → Popup message
* `prompt()` → Input from user
* `confirm()` → Yes/No dialog
* `console.log()` → Debug output

```js
let age = prompt("Enter your age");
console.log(age);
```

---

## 4. Data Types

### 4.1 Primitive Data Types

Stores **single values**

* Number
* String
* Boolean
* Undefined
* Null

```js
let num = 10;
let name = "JS";
let isValid = true;
```

### 4.2 Non-Primitive Data Types

Stores **multiple values or reference values**

* Array
* Object
* Function

---

## 5. Operators

### 5.1 Arithmetic Operators

Used for mathematical operations

```js
let x = 5;
x++;
--x;
```

### 5.2 Assignment Operators

Used to assign values

```js
let a = 10;
a += 5;
```

### 5.3 Comparison Operators

Used to compare values

```js
5 == "5";   // true
5 === "5";  // false
```

### 5.4 Logical Operators

Used to compare conditions

* `&&` AND
* `||` OR
* `!` NOT

---

## 6. Strings

### 6.1 String Concatenation

```js
let a = "Hello";
let b = "World";
console.log(a + " " + b);
```

### 6.2 Template Literals

Used for **string interpolation**

```js
let lang = "JavaScript";
console.log(`${lang} is powerful`);
```

---

## 7. Type Conversion

### 7.1 Implicit Conversion

Automatically handled by JS

```js
"10" + 5; // "105"
10 + true; // 11
```

### 7.2 Explicit Conversion

Manually converted

```js
Number("10");
Boolean(1);
String(123);
```

---

## 8. Control Flow Statements

### 8.1 if…else

```js
if(age >= 18){
  console.log("Adult");
}else{
  console.log("Minor");
}
```

### 8.2 Ternary Operator

```js
age >= 18 ? "Adult" : "Minor";
```

### 8.3 Switch Statement

```js
switch(day){
  case "Monday": console.log("Weekday"); break;
  case "Sunday": console.log("Holiday"); break;
  default: console.log("Invalid");
}
```

---

## 9. Looping Statements

### 9.1 for Loop

```js
for(let i=1;i<=5;i++){
  console.log(i);
}
```

### 9.2 while Loop

```js
let i = 5;
while(i > 0){
  console.log(i);
  i--;
}
```

### 9.3 do…while Loop

```js
do{
  console.log(i);
  i++;
}while(i < 5);
```

---

## 10. Arrays

**Array**: Used to store **multiple values in a single variable**.

```js
let skills = ["HTML", "CSS", "JS"];
console.log(skills[0]);
console.log(skills.length);
```

---

## 11. Objects

**Object**: Collection of **key-value pairs**.

```js
let vehicle = {
  type: "Car",
  color: "Red",
  price: 100000
};
console.log(vehicle.price);
```

---

## 12. Functions

**Function**: A block of reusable code that performs a specific task.

### 12.1 Function Declaration

```js
function greet(name){
  return `Hello ${name}`;
}
```

### 12.2 Default Parameters

```js
function user(name="Rajesh"){
  console.log(name);
}
```

### 12.3 Return vs Non-Return

```js
function add(a,b){
  return a+b;
}

function show(){
  console.log("No return");
}
```

---

## 13. Scope

### Function Scope

`var` is function scoped

### Block Scope

`let` and `const` are block scoped

---

## 14. Function Types

* Named Function
* Anonymous Function
* Arrow Function
* IIFE (Immediately Invoked Function Expression)

```js
(() => {
  console.log("IIFE");
})();
```

---

## 15. Internal & External JavaScript

* Internal JS → `<script>` inside HTML
* External JS → Separate `.js` file linked using `<script src="file.js"></script>`
