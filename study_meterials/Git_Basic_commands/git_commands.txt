🔹 Add & Commit:
git add .              # Add all changes
git commit -m "msg"    # Commit with message
git push               # Push to remote

🔹 Check Status & History:
git status              # Check repo status
git log                 # Commit history (press Q to quit)
git show                # Show last commit details
git diff                # Show file changes

🔹 Branch Commands
git branch              # List branches
git checkout branchname # Switch branch
git checkout -b new_branch   # Create & switch to new branch
git branch -d new_branch     # Delete branch

🔹 Pull & Merge:
git pull                # Fetch + merge from remote
git merge branchname    # Merge branch into current branch

🔹 Reset (Revert Changes):
git reset file_name     # Unstage a file

Undo last commit:
git reset --soft HEAD~1   # Keeps changes staged
git reset --hard HEAD~1   # Deletes commit + changes (DANGER)
⚠️ --hard will permanently remove changes.

🔹 Amend Last Commit:
git commit --amend
✔️ Used to modify last commit message or files.

🔹 Force Push:
git push --force
⚠️ Use only when you changed commit history
(Reset / Amend)
